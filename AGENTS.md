# Contributor context for coding agents

This repository contains one Omarchy plugin at its root. Start with README.md, manifest.json and THIRD_PARTY_NOTICES.md. QML is the UI; Service.qml owns shared state, polling and serialized task mutations; backend.py adapts local system records; daily.py handles tasks and conservative weather notifications; integrations.py handles optional external APIs. ui/ contains rendering components and motion profiles.

The plugin ID is bappoz.notch. Entry points are Service.qml, Notch.qml and DesktopOsd.qml. The panel routes the Omarchy volume OSD to Notchi and preserves other OSD messages. Runtime.qml shares the service across bar widgets. Never introduce credentials or machine-specific desktop configuration. Do not change existing task/photo schemas without migration. Usage quotas are consumed allowance; native recentDays.messageCount contains tokens despite its legacy name. Unknown values must remain unknown. The disk bar represents free space. Weather/agent notices share a deduplicated queue; initial load, resume and locked sessions must not replay alerts. 3D effects transform a visual snapshot, never the live input plane.

Validate with `omarchy plugin validate .`. For visual changes, run the UI on a disposable profile and verify all nine opening styles, hover exit, pinned navigation, reduced motion and provider return navigation. Never exercise a real camera, account mutation or network credentials as a test without authorization. Keep sources, screenshots and limitations documented.
